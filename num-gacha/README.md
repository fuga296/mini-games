# NUM GACHA (数字ガチャ)

**キャラではなく数字が出るガチャ。1 から 9,007,199,254,740,991 までの数字を集める。**

## 何か

- 12時間ごと (端末の時計で 0:00 と 12:00) に、5回まわせるようになります。回数は貯まりません。
- 出るのはただの数字です。桁ごとに出る確率が決まっていて、桁が上がるほど出にくくなります(1桁 約16%、4桁 約12%、8桁 約6%、12桁 約1%、16桁 約0.02%)。同じ桁の数字はどれも同じ確率です。
- 一番大きい数字 9,007,199,254,740,991 (JavaScript で正確に扱える整数の最大値) は、毎日遊んで数年に一度出るかどうかの確率 (約 1/30,000。桁ごとの確率を決める式から出た結果で、最大値だけの設定はありません) です。
- 同じ数字を10枚集めると「1つ上の数字を出した」ことになります。その数字が未解放なら解放され、解放済みなら1枚増えます。繰り上がりは連鎖します (1 が10枚 → 2 が1枚 → 2 が10枚なら 3 …)。
- 出た数字はコレクション画面で見られます。未解放の欄も表示します。

## 使い方

1. `index.html` をブラウザで開きます (スマホ可。サーバーは要りません)。
2. 「ガチャ」画面で「1回まわす」か「まとめてまわす」を押します。演出中はタップで先へ進み、「スキップ」で結果一覧へ飛べます。
3. 「コレクション」画面で集めた数字を見ます。表示は2種類あり、上のボタンで切り替えます。
   - **桁ごとに折りたたむ**: 1〜16桁ごとに開閉。長く続く未解放は「未解放 n 個」の1行に省略。
   - **10進ズーム**: 大きな範囲から10等分ずつ絞り込む (例: `3,4xx,xxx`)。
4. パソコンでは1画面に収まる配置になり、ガチャ画面では集計・最近出た数字・提供割合を常に見られます(幅960px以上・高さ560px以上のとき。スマホは縦にスクロール)。
5. 数字のマスをタップすると、手持ち枚数 (繰り上がりまであと何枚か)・累計・初入手日時・出る確率が出ます。
6. 「提供割合」でランクごとの確率を見られます。

## 注意

- **更新時刻は端末の時計に依存します。** 端末の時刻・タイムゾーンで 0:00 / 12:00 を判断します。時計を進めると回数が回復し、戻しても回数は増えません (サーバーがないので不正は防げません)。
- データはブラウザ内 (`localStorage`) にだけ保存されます。ブラウザのデータを消す・別の端末やブラウザで開く・プライベートモードで開くと、記録は引き継がれません。
- 外部との通信、ログイン、課金はありません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 (見た目) |
| `ui.js` | 画面の動き・演出 |
| `logic.js` | 抽選・繰り上がり・更新・保存のロジックと設定 (`CONFIG`) |
| `DESIGN.md` | 分布の式、桁ごとの確率、10年シミュレーション、決めた値の理由と代替案 |
| `tools/simulate.js` | シミュレーション (`node num-gacha/tools/simulate.js [人数] [1日の回数] [年数] [tailStrength]`) |

設定 (確率の形・回数・更新間隔・繰り上がり枚数・レア度の区切り) は `logic.js` の `CONFIG`、コレクション画面の省略のしかたは `ui.js` の `UI` で変えられます。
