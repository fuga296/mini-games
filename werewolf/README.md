# 人狼ゲーム

**一行説明：** スマホ1台で遊べる、普通の人狼ゲーム（司会なしで回す形と、司会の支援の2通り）。

## 何か

村人と人狼に分かれて、話し合いと投票で相手を見つけ出す推理ゲームです。
配役、夜の行動の解決、投票の集計、勝敗の判定はアプリが受け持ちます。
通信、ログイン、課金はありません。データは端末の中にだけ保存されます。

- 人数：4〜20人（おすすめ 5〜12人）
- 役職：村人・人狼・占い師・霊媒師・騎士・狂人・妖狐
- 動作：`index.html` をブラウザで開くだけ（サーバー不要、`file://` でも動きます）

## 遊び方

### スマホ1台を回す（司会なし）

1. 「スマホ1台を回す」を選び、座っている順に名前を入れて「ゲームを始める」を押します。
2. **役職の確認**：画面に出た名前の人にスマホを渡します。本人が「〇〇です（開く）」を押して役職を見て、「確認した」で閉じます。これを全員で繰り返します。
3. **夜**：もう一度全員に順番に回します。能力のある人は対象を選びます。能力のない人もダミーの選択をするので、操作の長さで能力者だとは分かりません。占い師は選んだ直後に結果を見られます。
4. **朝・昼**：犠牲者が発表されます。タイマーを動かして話し合います。
5. **投票**：1人ずつスマホを回して秘密に投票します（設定で「指差しでまとめて入力」にもできます）。開票すると処刑者が発表されます。
6. 3〜5 を、決着がつくまで繰り返します。

### 司会役の支援

1. 「司会役の支援」を選びます。司会は参加者に含めません。
2. 役職の確認だけは、スマホを全員に回して本人に見せます。そのあと司会に戻します。
3. **夜**：司会は画面の台本（「人狼の人は目を開けてください」など）を読み、指差された人を入力します。占いと霊媒の結果は画面に出るので、司会が手で示します。生存者がいない役職も台本を読みます（呼ばないと、その役職が死んでいるとばれるため）。
4. **昼・投票**：タイマーを使い、投票は「誰が誰を指差したか」を入力して開票します。
5. 司会メモを開くと、全員の役職と秘密の記録を見られます。

### 勝ち負け

- 人狼が全滅すれば **村人陣営** の勝ちです。
- 人狼の数が人間（人狼以外）の数以上になれば **人狼陣営** の勝ちです。狂人も人狼陣営です。
- 妖狐がいる場合、決着したときに妖狐が生きていれば **妖狐** の単独勝ちです。

## 設定（「細かいルール」で変更できます）

| 項目 | 既定値 | 理由 | 代替案 |
|---|---|---|---|
| 昼の話し合い時間 | 3分 | 対面の5〜9人で、1周意見を言って少し議論できる長さ | 大人数や初心者は5分。慣れた人は2分 |
| 初日の夜の襲撃 | なし | 何も話していないうちに1人が脱落すると、その人が退屈する | 「あり」にすると早く進む（少人数向け） |
| 初日の夜の占い | 自由に占う | 対面ではいちばん分かりやすい | お告げ（ランダムな人間を1人知る）／なし |
| 騎士の連続護衛 | 不可 | 同じ人を守り続けると占い師が死ななくなり、偏るため | 可 |
| 騎士の自分護衛 | 不可 | 騎士が強くなりすぎないように | 可 |
| 投票が同数のとき | 決選投票 | 対面の人狼でよく使われる | ランダムで処刑／処刑なし |
| 決選投票も同数のとき | ランダムで処刑 | 処刑なしにすると人狼に有利な引き延ばしが起きやすい | 処刑なし |
| 人狼の襲撃先が割れたとき | 候補からランダム | 人狼どうしは前の人の選択を見られるので、割れるのはまれ | 襲撃なし |
| 投票結果の公開 | 誰が誰に入れたか | 推理の材料が増え、話し合いが進む | 票数だけ |
| 自分への投票 | 不可 | 一般的なルール | 可 |
| 死亡時の役職公開 | 公開しない | 一般的な人狼のルール。霊媒師の意味がある | 公開する（初心者向け） |
| 投票のしかた（回す形） | 1人ずつ秘密に入力 | 回す形では誰が誰に入れたかを見られずに入力できる | 指差しでまとめて入力（早い） |
| 能力のない人の夜の操作 | ダミーの選択をさせる | 操作の長さで能力者だと分からないように | 確認だけ（早い） |

人数ごとのおすすめ配役は `rules/standard.js` の `presets` にあります。準備画面で自由に変えられます。

## ファイル

```
werewolf/
├── index.html          画面（HTML と CSS）
├── ui/app.js           画面の動き（ブラウザ専用）
├── ui/text-ja.js       日本語の文言と司会の台本（DOM 非依存）
├── core/engine.js      ゲームエンジン（汎用、ブラウザ非依存）
├── core/session.js     操作者の権限と通知（各自の端末で遊ぶ形への差し込み口）
├── core/rng.js         種つき乱数
├── core/module.js      ブラウザと Node の両方で読み込むための小さな仕組み
├── rules/standard.js   普通の人狼のルール（役職・行動・段階・勝利条件・設定）
├── tests/              ロジックのテスト
└── DESIGN.md           設計と、変則人狼の載せ方
```

## テスト

```bash
cd werewolf && npm test
```

Node 18 以上が必要です。外部のパッケージは使いません。
