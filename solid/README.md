# solid — 立体のミニゲーム集

内部が見えない・触れない立体を、共通の「層の切り替え」と「盤面の回転」で遊ぶ3つのゲーム。

| ゲーム | 一行説明 |
| --- | --- |
| [立体マインスイーパー](minesweeper/) | 26方向に数える、立方体の中のマインスイーパー。 |
| [3D迷路](maze/) | 「上」のない立体迷路を、自分の向きだけを頼りに進む主観視点の迷路。 |
| [63パズル](puzzle63/) | 4×4×4 の立体スライドパズル(15パズルの立体版)。 |

`index.html` を開くと一覧から選べます。各ゲームの `index.html` を直接開いても動きます(サーバー不要・`file://` 可)。スマホ対応、日本語 UI。

## 共通の操作(`common/solid.js`)

3つのゲームで同じ部品を使います。

- **盤面全体を回す**: 1本指/左ドラッグで自由に回す(画面上の動きに沿って回るトラックボール方式)。
  立体マインスイーパーと63パズルでは、盤面の右下に重ねた**回転パッド**(`Z⟲ ↑ Z⟳ / ← ⊞ → / ＋ ↓ －`)で回す。タップで画面の横(x)・縦(y)・奥行(z)軸まわりに 90° ずつ、**押し続けるとなめらかに連続回転**、`＋` `－` は拡大縮小(押し続けで連続)。`⊞` で最も近い「軸がそろった向き」(24通り)にそろえ、長押しで初期化。3D迷路の全体図は下のパネルの同じ並びのボタン。
  左下の矢印は盤面の X(赤)・Y(緑)・Z(青) 軸がいまどちらを向いているかを示す。
- **拡大縮小・移動**: ピンチ/ホイール/`＋` `－` で拡大縮小。2本指ドラッグ、右ドラッグ、Shift+ドラッグで移動。
- **層(レイヤー)の切り替え**: 「全体 / 単層 / ここまで」と、切る軸 X/Y/Z、`◀ ▶` かスライダーで層を選ぶ。
  「単層」は1枚だけ、「ここまで」は 1 層目から選んだ層までを表示(その先を切り取った断面)。
  「前後を薄く」をオンにすると、表示範囲のすぐ隣の層を半透明で表示する。選んだ層は黄色い枠で示す。
- **タップと長押し**: 10px 以上動かなければタップ、450ms 押し続けると長押し(振動あり)。
- **キー**: `I` `K` / `J` `L` / `U` `O` で X/Y/Z 軸回転、`P` 軸にそろえる、`0` 初期化、`+` `-` 拡大縮小、`[` `]` 層、`\` 層の軸、`M` 層の表示方法。

数値(タップ判定の距離、長押し時間、回転の速さ、拡大の範囲など)は `common/solid.js` 冒頭の `Solid.CONFIG` で変えられます。

## ファイル

```
solid/
  index.html          一覧
  common/solid.js     共通部品(ジェスチャー・ビューア・回転ボタン・層の切り替え)
  common/solid.css    共通の画面の割り付け
  common/three.min.js three.js r170(同梱)
  common/three-LICENSE.txt
  minesweeper/  maze/  puzzle63/   各ゲーム(index.html, game.js, README.md)
```

## 外部との通信について

すべて同梱ファイルだけで動きます。実行時にネットワークへアクセスしません(CDN・フォント・解析・API・ログイン・課金なし)。
