# 63パズル

**一行説明**: 4×4×4 の立体スライドパズル(15パズルの立体版)。

## 何か

4×4×4 のマスに 1〜63 のピースと空きが 1 つ。空きに隣のピースを滑り込ませて、番号順にそろえます。

- 完成形: 番号 k のピースは位置 `x + 4y + 16z = k−1` にあります。1 が X・Y・Z すべて最小の角、63 はその反対の角の 1 つ手前で、反対の角が空きです。完成時の Z 層ごとにピースの色が違います。
- 動かせるのは、**空きを通る X・Y・Z 軸に平行な 3 本の線の上のピースだけ**。この 3 本の線は常に赤(X)・緑(Y)・青(Z)の線で示し、線上のピースは明るく、それ以外は半透明で表示します。
- シャッフルは、完成形から 300 手ランダムに逆に動かして作ります(直前の手を戻す動きは除く)。そのため必ず解けます。
- 手数は、ピースが 1 マス動くごとに 1 手と数えます。

## 使い方

- **← ↑ ↓ → のボタン / 矢印キー / WASD**: 画面のその方向へ、空きの隣のピースを 1 つ滑らせます。どの軸が動くかは、パズルの今の向きで決まります(画面上でその方向に最も近い軸)。
- 画面に垂直な(奥行き方向の)軸へ動かすには、**パズルを回転**して、その軸を画面の上下左右に向けます(回転ボタン `X↑` など、またはドラッグ)。
- **線上のピースをタップ**: そのピースと、空きとの間のピースがまとめて空きの方へ動きます。**空きの方へスワイプ**しても動きます。
- ピースのない所をドラッグすると回転。拡大縮小・層の切り替えは 3 作共通の操作です([../README.md](../README.md))。

## 設定で変えられる値

`game.js` 冒頭の `CONFIG`、または画面の ⚙: シャッフル手数(300)、ピースの大きさ(0.84)、線の外のピースの不透明度(0.16)、一辺のマス数(4。2〜6 にすると 7・26・124・215 パズル)、1 マス動く時間、スワイプ方向の許容角。
