# 鬼操作力ゲーム

> 玉をゴールへ運ぶだけ、なのに操作方法がステージごとに狂っている操作力試験ゲーム。

## 何か

ゲームの中身はわざと単純にしています(白い玉を緑のゴールへ運ぶだけ)。難しさはすべて「操作方法」から来ます。ステージは 5 つあり、それぞれ操作方法が違います。

| # | 名前 | 操作の狂い方 |
|---|------|--------------|
| 1 | あべこべ | 方向キーの割り当てがずれている(↑=右、→=下、↓=左、←=上) |
| 2 | 氷の上 | 入力は速度ではなく**加速度**。慣性で滑り、止まるには逆に押す |
| 3 | 遅れて届く | 入力が約 0.7 秒**遅れて**届く |
| 4 | 回る世界 | 入力の向きが毎秒 45° ずつ**回転**し続ける(左上の矢印が「↑キーで進む向き」) |
| 5 | 躍度 | 入力は加速度の**変化(躍度)**。離しても加速度が残る |

- 灰色の壁は跳ね返ります。赤い斜線(トゲ)に触れるとスタートに戻されます(タイマーは止まりません)。
- 玉から伸びる青い矢印は速度、桃色の矢印は加速度です。
- クリアタイムは各ステージの自己ベストを、ブラウザの `localStorage` にだけ保存します。外部通信・サーバー・ログインはありません。

## 遊び方

`index.html` をブラウザで開くだけです(ビルド不要)。

- **PC**: 移動 `←↑↓→` または `WASD`、やり直し `R` / `Space`、メニュー `Esc`、クリア後に次へ `Enter`
- **スマホ**: 画面下の十字ボタン(▲◀▼▶)。指を押したまま滑らせても切り替わり、2 本指で斜め入力もできます。
- 最初に動かした瞬間からタイマーが始まります。

## 設定

メニューの「⚙ 設定」から各ステージの数値(速さ、加速度、摩擦、遅延、回転速度、躍度など)を変更できます。変更値はブラウザ内に保存されます。既定値から変えている間は、公平のためクリアタイムを記録しません。盤面の大きさ・玉の半径・反発係数などはファイル先頭の `CONFIG` / `STAGES` で変更できます。
