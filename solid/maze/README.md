# 3D迷路

**一行説明**: 「上」のない立体迷路を、自分の向きだけを頼りに進む主観視点の迷路。

## 何か

立方体の部屋が n×n×n に並び、6 方向(前後・左右・頭上・足元)へ通路がつながった立体迷路。主観視点で、角の部屋から黄色い八面体のゴールを目指します。

この世界には重力も決まった「上」もありません。操作も表示も、すべて自分の向きが基準です。

- 前進/後退は、いま向いている方向へ 1 部屋。
- 向きの変更は自分の軸で 90° ずつ: 左右を向く(↶ ↷)、頭の方/足の方を向く(⤒ ⤓)、その場で傾く(⟲ ⟳)。この組み合わせで 24 通りのどの向きにもなれます。
- 画面下の「通れる方向」も、ゴールの方向のヒント(設定でオン)も、自分から見た向き(前・後ろ・左・右・頭上・足元)で表示します。
- 壁の色は面の向きの軸で 3 色。同じ軸なら両側が同じ色なので、軸の区別はできても「上」は分かりません。

## 使い方

- **▲前進 / ▼後退**、**↶ ↷ ⤒ ⤓ ⟲ ⟳** のボタン、またはキー(`W`/`Space` 前進、`S` 後退、`A` `D`/`←` `→` 左右、`R` `F`/`↑` `↓` 頭の方/足の方、`Q` `E` 傾く)。
- **ドラッグ**: 自由に見回す。指を離すと一番近い向きにそろいます。大きく(約 45° 以上)ドラッグすると、その向きに変わります。
- **ピンチ/ホイール**: 視野の広さ(40〜110°)。
- **🗺 全体図**(`Tab`): 通った部屋とつながりを外から見ます。回転・拡大縮小・層の切り替えは他の 2 作と同じ共通操作です。水色の円すいが自分(先が前、白い棒が頭の方)、黄色がゴール。地図は開いたときの自分の向きから見た形で表示します。
- 大きさは 3〜8(標準 5×5×5 = 125 部屋)。ゴールはスタートから最も遠い部屋です。

## 設定で変えられる値

`game.js` 冒頭の `CONFIG`、または画面の ⚙: 大きさ(5)、回り道の割合(0 = 道が 1 通り)、霧の濃さ(0.22)、ゴール方向のヒント(オフ)、全体図に未通過の部屋も表示(オフ)、移動・回転のアニメーション時間、見回しの速さ、視野角。
